# 노노무라 병원 사람들 — New 3DS 네이티브 포팅

DOS 게임(사과나무팀 한글판)을 **자체 x86 에뮬레이터**로 3DS에서 직접 실행하는 홈브루입니다.
(DOSBox가 아니라 이 프로젝트 안에 들어 있는 CPU/VGA/EMS/XMS/마우스/OPL 음악 에뮬레이터입니다.)

- **상단 화면**: 게임 화면 (기본: 400x240 화면 가득 확대 / 메뉴에서 4:3 원본 비율로 변경 가능)
- **하단 화면**: 대사 텍스트를 다시 배치해서 표시 (게임이 글자를 그릴 때 글리프를 가로채서 확대). 게임이 폭에 맞춰 꺾어 둔 줄은 한 문단으로 이어 붙여 단어 단위로 다시 줄바꿈합니다.
- 대화창이 떠 있는 동안 **상단 화면에는 그림만** 크게 표시하고(대화창 띠는 숨김) 글자는 하단 화면에서만 보입니다. 일시정지 메뉴의 `Top: dialogue window`에서 Hidden/Shown 전환 가능(설정은 `win_hide`).
- 그림만 보일 때의 확대 방식은 `Top picture (no window)`에서 선택: **Fill**(기본: 그림 테두리를 잘라내고 400x240 화면 전체를 채움, 세로로 약간 늘어남) / **Stretch**(테두리 포함 전체를 화면에 꽉 차게 늘림) / **Fit**(비율 유지, 위아래 검은 띠). 설정은 `pic_mode`.
- 하단 화면은 대사가 없을 때 아무 글자도 표시하지 않습니다.
- **선택지(분기 메뉴), 세이브/로드 슬롯 목록**도 하단 화면에 크게 표시되고, 선택된 항목은 흰 막대로 강조됩니다.
- 글자 크기는 메뉴에서 Large / Medium(기본) / Small / Tiny 중 선택, 설정은 `nono_cfg.txt`에 저장됩니다.
- **음악**: OPL(FM) 칩을 본래 속도(49716 Hz)로 합성한 뒤 고품질 필터로 3DS DSP 기본 출력 속도(32728 Hz)로 변환합니다. (낮은 속도로 바로 합성하면 높은 소리가 접혀 들어와 지직거리는 소리가 납니다.) 합성 결과는 Nuked-OPL3(정확한 OPL 에뮬레이터)와 같은 연주 데이터로 비교해 음색(스펙트럼)이 1 dB 안팎으로 일치함을 확인했습니다.
- **소리 끊김 방지**: 에뮬레이션을 실제 시간보다 0.25초 앞서 돌려 그만큼의 소리를 항상 DSP에 쌓아 둡니다(화면 처리·저장이 잠깐 느려져도 음악이 끊기지 않음). 게임 데이터 파일(SILK*.DAT, SAGWA.* 등)은 시작할 때 RAM에 올려서 게임 중 SD 카드 읽기 지연이 없습니다(시작할 때 "Loading..."이 조금 길어집니다).
- 일시정지 메뉴의 `Sound test`는 에뮬레이터와 무관하게 음계 톤을 재생합니다. 톤은 깨끗한데 게임 음악만 깨진다면 에뮬레이션 쪽, 톤도 깨진다면 3DS 출력 쪽 문제입니다.

## 설치 (SD 카드)

```
SD:/3ds/nonomura.3dsx          ← 빌드된 홈브루 파일
SD:/3ds/nonomura/              ← 게임 파일 전부 (SILV1.COM, SILV.EXE, MUSICV.COM, SAGWA.*, FLAG*, SILK*.DAT ...)
```

세이브(FLAG0~8, SILK*.DAT)는 게임 폴더(`SD:/3ds/nonomura/`)에 그대로 저장됩니다.
문제가 생기면 같은 폴더의 `nono_log.txt`를 확인하세요 (속도/오류 기록).

## 조작

| 3DS | 동작 |
|---|---|
| 서클패드 | 마우스 이동 |
| 터치 드래그 / 탭 | 트랙패드 이동 / 왼쪽 클릭 |
| A / B | 왼쪽 클릭 / 오른쪽 클릭(취소) |
| 십자키 | 방향키 |
| X / Y | Enter / Esc |
| L / R | Ctrl / Space |
| ZL / ZR | 마우스 느리게 / 빠르게 (New 3DS) |
| SELECT (누르고 있는 동안) | 상단 화면에 성능 수치(속도%, CPU%, 쌓인 소리 ms, 소리 끊김 횟수) 표시 |
| START | 일시정지 메뉴 (하단 글자 크기, 상단 화면 확대/원본, 대화창 숨김, 그림 확대 방식, CPU 속도, 마우스 속도, 소리 테스트, 종료) |

## 빌드

GitHub Actions(`.github/workflows/build.yml`)가 `ctr/nonomura.3dsx`를 만들어 줍니다.
로컬 빌드: devkitARM + libctru 설치 후 `make -C ctr`.

## 구조

- `core/` — x86(386 실모드) 인터프리터, DOS/BIOS/EMS/XMS/마우스 HLE, VGA, OPL2/OPL3, 대사 캡처(textcap)
- `ctr/` — 3DS 프런트엔드 (화면, 입력, 오디오, 메뉴)
- `host/`, `test/` — PC에서 돌려 보는 테스트 러너

## 알려진 한계

- 게임 속도는 실제 시간(시스템 시계)에 맞춰 돌리고, 대기 구간(키 입력/타이머 대기)은 에뮬레이션을 건너뛰어 CPU를 아낍니다. 소리는 버리지 않고 쌓아 두었다가 재생합니다. 메뉴 하단에 Speed(%)와 CPU 사용률이 표시됩니다.
- 실기기 테스트는 계속 진행 중입니다. 속도가 부족하면 에뮬레이션 CPU 속도를 자동으로 낮춰 실시간에 맞춥니다(게임이 약간 느려질 수 있음).
- 하단 대사 확대는 이 게임 엔진(SILV)의 글자 그리기 루틴을 기준으로 합니다.
- 선택지 강조(흰 막대)가 바뀌는 순간 화면이 잠깐 불완전해도 글자를 지우지 않고 숨겨 두었다가 되돌립니다(0.4초 안에 복구되지 않으면 삭제).
