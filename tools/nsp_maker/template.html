노노무라 병원의 사람들 XP for Switch

게임 파일을 넣어 스위치에 설치되는 NSP 를 만듭니다. 파일은 이 기기 안에서만 처리되고 어디로도 보내지지 않습니다.
제작자 : 디시인사이드 스위치CFW 갤러리 -루카- · __BASEINFO__

1원본 게임 (필수)

CD 이미지 분할 압축(Disc.zip + Disc.z01 둘 다), CD 이미지(.img / .iso / .bin), 또는 게임 폴더의 MES.ARC · BG.ARC · DATA.ARC · MUSIC.ARC · VOICE.ARC 를 고르세요. 여러 개를 한 번에 고를 수 있습니다.

2언어

다른 한글 패치 파일(mes.arc, Bg.Arc)을 쓰려면 여기서 고르세요. 고르면 내장 패치 대신 그 파일을 씁니다.

+도스판 그림 (선택)

도스판(DOS) 게임 zip 또는 그 안의 SILK0.DAT ~ SILK4.DAT 를 고르면, 게임 중 - 버튼으로 윈도우판 그림과 도스판 그림(16색)을 바꿔 볼 수 있습니다. 약 5.5MB 가 더해집니다.

3prod.keys (필수)

본인 스위치에서 Lockpick_RCM 으로 뽑은 prod.keys. NSP 를 스위치 형식으로 암호화하는 데만 쓰이고 어디로도 보내지지 않습니다.

4만들기

배경음악은 크기를 줄이도록 압축합니다(263MB → 약 66MB). 결과 NSP 는 약 300MB 이며, 휴대폰에서는 1~3분 걸릴 수 있습니다. 그동안 화면을 끄지 마세요.

설치와 실행

1) 만든 NSP 를 SD 카드에 복사하고 DBI · Tinfoil · Awoo 같은 설치 프로그램으로 설치합니다.
2) 홈 메뉴에서 실행합니다. 저장 파일은 SD 카드 switch/nonoxp/save/ 에 생깁니다.
3) 서명 패치(sigpatches)가 있는 커스텀 펌웨어(Atmosphère)가 필요합니다.
4) SD 카드 switch/nonoxp/ 에 같은 이름의 파일을 두면 NSP 안의 것 대신 그 파일을 씁니다.
