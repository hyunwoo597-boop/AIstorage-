河原崎家の一族 대사 편집기

일본어 대사 옆에 한국어를 적어 넣고 mes.ARC 를 만들어 스위치 포팅판에 넣는 도구입니다. 파일은 이 기기 안에서만 처리됩니다.
제작자 : 디시인사이드 스위치CFW 갤러리 -루카-

1. 불러오기

원본 mes.ARC 하나, 또는 CD 이미지 분할 압축(.zip + .z01 + .z02 모두)을 고르세요. 이 도구로 만든 mes.ARC 를 다시 고르면 적어 둔 번역이 그대로 이어집니다(번역 정보가 파일 안에 들어 있습니다).

2. 번역하기

줄바꿈은 그대로 게임의 줄바꿈이 됩니다. 대사창 한 줄은 한글 약 35자이고, 긴 문장은 저절로 다음 줄로 넘어갑니다. 대사창에는 4줄까지 들어갑니다. 한글 음절 11,172자와 일본어 글꼴에 있는 문자(한자·문장부호·영숫자)를 쓸 수 있습니다.

자동 번역 (일본어 → 한국어)

초벌 번역을 넣어 주는 기능입니다. 자동 번역한 줄은 검토 필요 표시가 붙고, 직접 고치면 표시가 없어집니다. 인터넷 연결이 필요합니다.

키는 이 기기의 브라우저에만 저장되고 Anthropic 서버(api.anthropic.com)로만 보내집니다. 사용 요금은 키 주인에게 청구됩니다.

용어집 — 한 줄에 하나씩 일본어=한국어 (예: 京子=쿄코). 이름을 항상 같게 옮길 때 씁니다.

휴대폰 브라우저 번역 쓰기 (무료)

크롬 또는 삼성 인터넷의 "페이지 번역"으로 일본어 원문만 번역한 뒤, 그 결과를 빈 칸에 가져옵니다. 편집기 글자와 내가 쓴 번역은 번역되지 않게 막아 두었습니다.
① 위에서 파일·보기를 골라 번역할 줄을 화면에 띄우기 → ② 크롬: 오른쪽 위 ⋮ → 번역… (삼성 인터넷: ≡ → 번역) → 한국어 선택 → ③ 아래로 쭉 내려 원문이 다 한국어로 바뀐 걸 확인 → ④ 아래 버튼. 한 번에 80줄씩 보이니 "더 보기"로 늘리면 더 많이 할 수 있습니다.

3. 저장하기

작업 내용은 이 브라우저에 자동으로 저장됩니다. 다른 기기로 옮기거나 백업하려면 작업 파일을 받아 두세요.

적용: 만든 mes.ARC 를 SD 카드 switch/Kawarazaki/ 폴더에 넣으면 설치한 스위치 포팅판이 이 파일을 먼저 읽습니다(폴더가 없으면 만드세요). 한글이 보이려면 한글 글꼴이 들어간 포팅툴(이 편집기와 같이 받은 판 이후)로 만든 NSP 가 설치되어 있어야 합니다. 대사를 고친 장면 안에서 한 세이브는 그대로 불러와집니다(대사 번호 기준).
