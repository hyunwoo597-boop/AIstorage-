河原崎家の一族 for Switch

게임 파일을 넣어 스위치에 설치되는 NSP 를 만듭니다. 파일은 이 기기 안에서만 처리되고 어디로도 보내지지 않습니다.
제작자 : 디시인사이드 스위치CFW 갤러리 -루카-__BASEINFO__

1원본 게임 (필수)

CD 이미지 분할 압축(.zip + .z01 + .z02 모두), CD 이미지(.img / .iso / .bin), 또는 게임 폴더의 mes.ARC · gcc.ARC · sequence.ARC · voice.ARC · bgm.AWF · effect.AWF · effect2.AWF · effect3.AWF 를 고르세요. 여러 개를 한 번에 고를 수 있습니다.

2prod.keys (필수)

본인 스위치에서 Lockpick_RCM 으로 뽑은 prod.keys. NSP 를 스위치 형식으로 암호화하는 데만 쓰이고 어디로도 보내지지 않습니다.

3만들기

결과 NSP 는 약 560MB 이며, 휴대폰에서는 몇 분 걸릴 수 있습니다. 그동안 화면을 끄지 마세요.

설치와 실행

1) 만든 NSP 를 SD 카드에 복사하고 DBI · Tinfoil · Awoo 같은 설치 프로그램으로 설치합니다.
2) 홈 메뉴에서 실행합니다. 저장 파일은 SD 카드 switch/Kawarazaki/save/ 에 생깁니다.
3) 서명 패치(sigpatches)가 있는 커스텀 펌웨어(Atmosphère)가 필요합니다.
4) 수정 패치는 SD 카드 atmosphere/contents/01004B4157410000/exefs/main 을 바꾸면 됩니다(다시 설치할 필요 없음).
